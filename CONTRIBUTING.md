# Contributing

Thank you for improving Project Foundation.

1. Open an issue for behavior or compatibility changes before a large implementation.
2. Keep installer behavior interactive and preserve the no-telemetry policy.
3. Do not add Git mutations to installation workflows.
4. Add tests for filesystem and topology changes.
5. Run `bun run check` before opening a pull request.

See [Development](docs/development.md) for architecture and commands. Compatibility changes must cite
the current primary agent documentation in [Compatibility sources](docs/compatibility.md).
